Stasiun pemantau BMKG: Indrapuri

Pengukuran PM2.5 langsung dari sensor di Indrapuri, Aceh Besar (sekitar 25 km dari Banda Aceh), sebagai pembanding data model di atas. Angka terkini dan grafik riwayat dapat dilihat di situs BMKG.

Tautan keluar ke situs BMKG. Situs ini tidak berafiliasi dengan BMKG, dan angka dari stasiun tersebut tidak ditampilkan di sini.

Lihat data di BMKG ↗
Kenapa angkanya bisa berbeda dengan BMKG?
  1. Model, bukan sensor. BMKG mengukur langsung di lapangan dengan alat. Dashboard ini menampilkan perkiraan model atmosfer global (CAMS). Jika berbeda, pengukuran BMKG yang menjadi rujukan.
  2. Resolusi model kasar. Satu kotak model sekitar 45 km dirata-rata, sehingga lonjakan lokal (asap pembakaran, debu jalan, lalu lintas padat) tidak tertangkap. Angka model cenderung lebih rendah di dekat sumber polusi.
  3. Lokasi berbeda. Stasiun BMKG berada di Indrapuri, Aceh Besar, sekitar 25 km dari titik koordinat dashboard ini.
  4. Skala berbeda. Dashboard menampilkan US AQI dan perkiraan ISPU yang dihitung sendiri dari PM2.5 model, sedangkan BMKG menampilkan konsentrasi PM2.5 (µg/m³) hasil pengukuran dengan kategorinya sendiri. Titik batas dan cara hitung tiap skala berbeda, jadi cara paling adil adalah membandingkan angka PM2.5 dengan PM2.5.
  5. Waktu pembaruan. Model diperbarui beberapa kali sehari dan nilai “saat ini” adalah interpolasi per jam, sehingga kejadian mendadak bisa terlambat atau meleset waktunya.

Singkatnya: untuk angka resmi dan pengukuran aktual, rujuk BMKG. Dashboard ini hanya gambaran umum dari data model.
